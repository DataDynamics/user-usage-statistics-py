# 사용자 작업 이력 집계

시각화 작업 로그(CSV)를 읽어 사용량·성능 통계를 엑셀과 차트(PNG)로 생성합니다.

## 입력 형식

헤더 없음, 구분자 `,`, UTF-8.

```
Job종류,사용자명,"총데이터수",차트수,시작일시,종료일시,경과시간
View,fharenheit,"887,576",18,2026-10-10 0:11:11,2026-10-10 0:14:16,3:05
```

- 총데이터수는 3자리 콤마가 있어 `""`로 감싸며, `""` 안의 앞뒤 공백은 trim 처리
- 일시의 시(hour)는 `0`~`23` (한 자리는 0 패딩 없음)
- 경과시간은 `m:ss` — 분은 `0`부터 시작해 10 이상이면 두 자리, 60분 이상도 그대로 표기 (`125:30`). `H:MM:ss`도 허용
- 모든 값(차트 수 포함)은 앞뒤 공백을 trim

## 실행

```bash
pip install -r requirements.txt
python usage_stats.py log.csv -o output --top 20 --sla 60
```

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `-o, --output` | 출력 디렉토리 | `output` |
| `--top` | Top N 사용자 수 | 20 |
| `--sla` | SLA 기준 소요초 | 60 |
| `--no-charts` | 차트 생성 생략 | |

테스트 데이터 생성: `python generate_sample.py -n 2000 -o sample.csv`

## 출력

- `output/usage_stats.xlsx` — 요약, Job종류별, 사용자별(등급·파레토), 일/주/월별 추이, 시간대·요일·히트맵, 구간별(데이터 규모·소요시간·차트수), 상관계수, 동시 실행, 이상치, 품질검증, 파싱오류, 원본(파생 컬럼 포함)
- `output/charts/*.png` — 일별 Job 수, 일별 소요시간(평균/P95), 월별 사용량, 시간대별, 요일×시간대 히트맵, Top 사용자, 데이터수/차트수 vs 소요시간 산점도, 소요시간 박스플롯·구간 분포, 데이터 규모별 소요시간
